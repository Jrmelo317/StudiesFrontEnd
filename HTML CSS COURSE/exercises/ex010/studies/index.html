Aprendendo a Mexer com Links

A tag que da um endereço de um link é a tag a, ela conta com os atributos href(que contém o link), target(que diz como deve abrir esse link, os principais são na própria janela _self e em outra janela _blank ) e hreflang (que diz qual é a língua do site contido no link).

Além disso, conta com o atributo rel, que indica qual o tipo de site de destino do link, sendo ele do autor, voltar no mesmo site, proximo documento no mesmo site, externo ou de site pagos.

Link para o próprio site

Usamos um link para o próprio site quando o link que vamos abrir irá manter a pessoa em nosso site, então na tag a usamos o atributo target="_self" que já é o padrão.

Esse link te mantém em nosso site, na mesma janela.

Link para site externo

Usamos este link para um site externo, assim abrimos ele em outra janela para manter o usuário em nosso site na janela já existente, isso é feito usando o atributo target="_blank".

Isso te levará para o meu github.

Arquivos de Download

Para fazer download de arquivos usamos a mesma tag de link externo a. Mas precisamos usar os atributos download, que indicara o nome com a extensão do que vai ser baixado, e o atributo type, que indica qual o tipo da aplicação que será baixada.
