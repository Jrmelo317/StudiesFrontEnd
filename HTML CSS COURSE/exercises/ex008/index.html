Principais Formatações

Negrito/Destaque

Nesta Frase temos um negrito usando a tag strong. Ela é semântica, ou seja, ela é focada no significado e não na forma. O Strong significa que dentro de um texto determinada frase ou palavra é forte, é de destque, e strong.

Itálico/Ênfase

Nesta frase temos um termo em itálico. Para isso cacabamos de utilizar a tag semântica EM.

Texto Marcado

Podemos criar também um texto marcado usando a tag MARK.

E no outro parágrafo, temos outro texto marcado no final.

Texto Grande e Pequeno

Estamos criando um texto grande e um texto pequeno neste parágrafo.

Texto Deletado

Podemos marcar um texto como excluído, para indicar que ele deve ser lido mas não considerado. Para isso utiliza a tag del.

Texto Inserido

Podemos marcar um texto como incluído para dar uma ênfase e indicar que ele foi inserido depois. Para isso utiliza a tag ins.

Existe também o texto sublinhado, que é não semântica e porntanto desatualizada, que utiliza a tag u(não semântica).
