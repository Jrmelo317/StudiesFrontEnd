Aprendendo Listas em HMTL5

Listas Ordenadas

Essas listas são chamadas pela tag ol, essa tag pode possuir os parâmetros type (que fala qual o tipo da contagem, seja númerica, romana, alfabética, maiúsculas ou minúculas) e o parâmetro start, que muda o número de começo da contagem, por exemplo se start="5" a contagem começará em 5. Cada item dessa lista é representado pela tag li, que possui fechamento opcional.

  1. item 1
  2. item 2
  3. item 3
  4. item 4
  5. item 5

Listas Não Ordenadas

Essas listas são marcadas pela tag ul, do prefixo un de negação do inglês (unordered), ela pode possuir o parâmetro type que configura qual o marcador de um item da lista, sendo disc (padrão), circle e square.

  • item 1
  • item 2
  • item 3
  • item 4
  • item 5

Lista de Definições

É como se fosse um dicionário, demarcado pela tag dl. Cada termo dessa lista tem um definition term, demarcado pela tag dt, e cada termo pode ter uma ou mais descrições chamadas de definition description, demarcado pela tag dd.

HTML
Linguagem de marcação utilizada para criar o conteúdo de sites.
CSS
Linguagem de marcação para especificação de estilos em sites.
JavaScript
Linguagem de programação para criar interatividade em sites.
