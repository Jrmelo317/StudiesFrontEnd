Imagens Dinâmicas, Aúdios e Vídeos

Imagens Flexíveis

O que acontece é que as imagens podem não caber em todos os formatos de tela, porque por exemplo a tela de uma tv é maior que um celular. Assim precisamos redimensionar as imagens de acordo com o tamanho da tela. Para isso usamos as tags <picture>, <source> e <img>.

Para visualizar suas configurações e descrição de utilização, retorne aos slides da aula 11.

Aúdios

A principal tag utilizada para aúdio é audio. Os seus principais atributos são: preload (que diz como a janela deve pre-carregar o som), controls (que diz se o controlador do aúdio será aparente ao usuário), autoplay (que se inserido iniciará a produção do aúdio assim que for carregado) e loop (que faz com que o aúdio repita eternamente).

Vídeos

A principal tag utilizada para vídeos no HTML5 é video. Os seus principais atributos são: width (indica a largura que o vídeo deve ter na tela), poster (configura a imagem que vai aparecer como capa enquanto o usuário não clicar no play), controls (configura se os controles aparecerão para o usuário) e autoplay (configura se o vídeo começará automaticamente).
